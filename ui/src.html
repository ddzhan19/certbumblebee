Certbumblebee

Zertifikate holen oder erstellen, ablegen, automatisch erneuern

Läuft nur auf diesem Rechner. Schlüssel und Passwörter bleiben hier; gesprochen wird nur mit dem Zertifikatsanbieter.

Neues Zertifikat einrichten

Das Programm holt das Zertifikat bei Let’s Encrypt oder erstellt ein selbstsigniertes, legt die gewünschten Dateien (PFX, Zertifikat, Schlüssel …) im Zielordner ab und erneuert sie später von selbst.

Domains

Eine Domain pro Zeile. Die Domains müssen im Internet auf diesen Server zeigen (öffentlicher DNS-Eintrag). Für Wildcards (*.beispiel.de) und Domains ohne öffentlichen Eintrag wählen Sie unten „DNS (Cloudflare)“. Nur intern genutzte Namen gehen auch mit „Selbstsigniert“.

Woher kommt das Zertifikat?

Bei jeder Erneuerung entsteht ein neues Zertifikat mit neuem Schlüssel. Geräte, die dem alten Zertifikat vertrauen, müssen dem neuen erneut vertrauen. Wählen Sie deshalb lieber eine lange Gültigkeit.

Es ist noch kein Cloudflare-Zugang hinterlegt.

Dafür braucht das Programm einen API-Token.

Bei mehreren Cloudflare-Konten sucht das Programm für jede Domain die Zone in allen Zugängen. Die Domains müssen bei Cloudflare als Zone angelegt sein.

Ein Ordner pro Zeile, wenn die Domains in verschiedenen Ordnern liegen. Der Server muss die Datei unter /.well-known/acme-challenge/ ausliefern.

Wohin kommen die Dateien?

Lokaler Ordner oder Netzwerkfreigabe im Format \\server\freigabe\ordner. Zugeordnete Laufwerke wie Z: sieht die automatische Aufgabe nicht.

Welche Dateien sollen dort liegen?

Wer den Ordner lesen darf, kann mit dem Schlüssel das Zertifikat benutzen. Geben Sie Ordner und Freigabe nur den Konten frei, die den Schlüssel brauchen.

PEM ist das Textformat mit „-----BEGIN CERTIFICATE-----“, das die meisten Server und Geräte erwarten. Binär (DER) brauchen vor allem ältere Windows-Programme. Zwischenzertifikate und fullchain bleiben bei DER im Textformat und enden auf .pem.

Das Passwort wird für die Erneuerung geschützt auf diesem Rechner gespeichert (Windows-Datenschutz-API, nur für Administratoren und das Systemkonto lesbar). Bitte zusätzlich selbst notieren, Sie brauchen es beim Import.

Erneuerung

Das Konto braucht das Recht „Als Batchauftrag anmelden“. Das Passwort geht nur an die Aufgabenplanung und wird nicht gespeichert.

Weitere Einstellungen

Der Anbieter schreibt nur bei wichtigen Hinweisen zum Konto.

Zum ersten Ausprobieren die Testumgebung wählen: Sie hat großzügigere Limits. Sie prüft auch, ob Port 80 wirklich aus dem Internet erreichbar ist.

„Kompatibel“ lässt sich auf allen Windows-Versionen, in IIS und Exchange importieren. „Modern“ können ältere Windows-Versionen nicht lesen.

    Eingerichtete Zertifikate

    DNS-Zugänge (Cloudflare)

    Mit einem Cloudflare-API-Token setzt Certbumblebee die DNS-Einträge für die Bestätigung selbst, je Zone, und löscht sie danach wieder. So gehen Wildcards (*.beispiel.de), und die Erneuerung läuft ohne Zutun. Der Token wird verschlüsselt auf dem Server gespeichert und nie wieder angezeigt.

    So legen Sie den Token bei Cloudflare an
    1. Bei Cloudflare anmelden, oben rechts das Profil öffnen, API-Tokens, dann Token erstellen.
    2. Die Vorlage Zone-DNS bearbeiten („Edit zone DNS“) verwenden oder einen eigenen Token anlegen.
    3. Berechtigungen: Zone – DNS – Bearbeiten und Zone – Zone – Lesen.
    4. Zonenressourcen: die Zone(n), für die Zertifikate entstehen sollen, oder „Alle Zonen“.
    5. Token erstellen und kopieren. Cloudflare zeigt ihn nur einmal.

    Der Token braucht nur diese beiden Rechte. Ein „Global API Key“ wird nicht benutzt und sollte auch nicht verwendet werden.

    Wildcard-Zertifikat holen

    Ein Wildcard-Zertifikat (*.beispiel.de) deckt alle Subdomains ab. Let’s Encrypt prüft es nur über einen DNS-Eintrag, den Sie bei Ihrem DNS-Anbieter selbst anlegen. Liegt die Domain bei Cloudflare, geht das automatisch: unter „Ausstellen“ die Methode „DNS (Cloudflare)“ wählen. Hier ist der manuelle Weg für alle anderen DNS-Anbieter. Er hat keine automatische Erneuerung: Etwa alle 60 Tage müssen Sie den Vorgang wiederholen.

    Eine Domain pro Zeile. Die Hauptdomain (beispiel.de) gehört nicht zur Wildcard und muss extra eingetragen werden.

    Es wird nirgends gespeichert. Bitte notieren.
